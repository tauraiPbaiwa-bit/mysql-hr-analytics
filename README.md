# MySQL HR Schema Analytics Project

This repository contains an implementation of the classic Human Resources (HR) database schema optimized for **MySQL**, alongside a series of practical analytical SQL queries designed to test intermediate data retrieval skills.

## Getting Started

### 1. Prerequisites
You will need a running instance of **MySQL Server** and a database client like **MySQL Workbench** or **DBeaver**.

### 2. Database Installation
1. Clone this repository or download the source files.
2. Run the initialization script to generate the database, tables, and seed data:
   ```bash
   mysql -u your_username -p < hr-schema.sql
